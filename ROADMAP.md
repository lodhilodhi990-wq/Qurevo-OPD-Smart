# QUREVO — Master Development & Deployment Roadmap

---

## Completed Roadmap Phases

- [x] **Phase 1 — Audit & Architecture**: Repository inspection, module structure, and audit records.
- [x] **Phase 2 — Shared Core & Design System**: Domain models (`Token`, `Patient`, `Doctor`) and Material 3 theme.
- [x] **Phase 3 — Ktor Backend & Queue Engine**: Netty server, WebSockets broadcast, and token queue state machine.
- [x] **Phase 4 — Local Outbox & Hybrid Cloud Sync**: Local outbox pattern, connectivity manager, and Supabase/Firebase integration.
- [x] **Phase 5 — Reception Android App**: 10 Compose screens, thermal ticket printing UI, and navigation.
- [x] **Phase 6 — Doctor Android App**: Consultation console with Next, Recall, Skip, Hold, Resume, Complete, Emergency controls.
- [x] **Phase 7 — Android TV & LED Display**: High-contrast TV view + Urdu & English TextToSpeech voice announcements.
- [x] **Phase 8 — Hospital Admin Android App**: Departments, doctors, rooms, devices, and reports.
- [x] **Phase 9 — Web Applications Hub**: PWA single-page web app for Web Reception, TV Display, Hospital Admin, and SaaS Super Admin.
- [x] **Phase 10 — Windows OPD Server Manager**: Desktop manager utility for Mode A Dedicated PC and Mode B Reception PC host setups.
- [x] **Phase 11 — Testing & Documentation**: Unit test suites, API docs, installation guide, and user manual.
