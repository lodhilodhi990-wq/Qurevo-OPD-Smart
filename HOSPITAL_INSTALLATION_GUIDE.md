# QUREVO — Hospital Installation Guide

1. **Hardware Preparation**: Ensure Reception PC and Doctor devices are connected to the hospital local router via Wi-Fi or Ethernet.
2. **Server Installation**: Run `./gradlew :tools:server-manager:run` on the Reception PC.
3. **App Setup**: Install `reception-app-debug.apk` and `doctor-app-debug.apk` on mobile devices.
4. **Auto Discovery**: Tap **Auto Discover Server** on client apps to pair automatically.
