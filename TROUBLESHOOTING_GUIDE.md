# QUREVO — Troubleshooting Guide

1. **Client App Cannot Find Server**: Ensure client device is on the same local Wi-Fi router as the Reception PC. Check port 27800 and 27801 firewall rules.
2. **TV Voice Silent**: Verify device media volume and speech synthesis engine settings.
3. **Cloud Sync Paused**: System is operating in Offline LAN mode. Cloud sync resumes automatically when internet returns.
